**Verdict**: typo-suggestion at the parser level is decades-old solved
prior art (git, 2008). MetaHarness's actual hazard is narrower — a hybrid
router+scaffolder overloading one positional argument as both "reserved
verb" and "arbitrary name" — which most peers simply avoid by construction
(npm namespaces it away, CRA/Vite are single-purpose, Yeoman fails closed).
Not an unsolved field problem; a design seam specific to this CLI's shape.

## Hypothesis

Given `npx metaharness <word>` where `<word>` is one of 23 words a CLI
user reasonably expects to be a diagnostic/info subcommand (the set grew
from 12 to 23 mid-session per the critic's round-2 finding below), when the
candidate guard is applied, then the CLI prints "looks like a command, not
a project name" and exits 2 instead of silently scaffolding and exiting 0,
subject to: (a) `--force` still scaffolds a project literally named one of
these words; (b) the pre-existing test locking in fallback behavior for
genuinely novel names (`unknown-name-here`) stays green unchanged; (c) the
known-verb list is now single-sourced (`METAHARNESS_VERBS`) for both the
guard's error message and (newly) the usage text.

**Verdict: ACCEPT-WITH-CAVEATS** (3 non-blocking, none fixed tonight):
1. Reserved list was real but incomplete — missed 11 real `harness`
   subcommands, live-tested by the critic as still scaffolding on round
   1's build. **Closed same night** (round 2 above): identical fix, same
   file, zero added risk.
2. `--force` now carries two meanings (pre-existing "overwrite existing
   target directory" plus new "scaffold this reserved word anyway") — a
   user retrying with `--force` could also silently overwrite an existing
   same-named directory with no separate confirmation. Narrow but real; a
   distinct flag would be safer. Disclosed, not fixed.
3. The guard runs once, before the `--wizard` block (which can later set
   `args.name` interactively) — a reserved word typed into the wizard's
   prompt bypasses it. Low real-world risk, real coverage gap. Disclosed,
   not fixed.
